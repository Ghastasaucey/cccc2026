智能电价预测与决策系统 - 素材与源码说明

一、项目说明
本目录基于“智能电价预测与决策系统”前端设计整理，提供可直接运行的静态前端源码、模拟数据集、模块脚本和本地启动脚本，可作为比赛提交中的“素材与源码”目录内容。

二、目录结构
1. index.html
   系统前端主入口文件，集成页面布局和模块挂载点。

2. js/core
   公共层代码：
   - state.js：全局状态管理
   - dataService.js：数据集加载
   - charts.js：Chart.js 图表渲染封装
   - utils.js：格式化、下载、通用工具函数

3. js/modules
   功能模块代码：
   - realtime.js：实时数据监控模块
   - history.js：历史数据查询模块
   - predict.js：预测参数设置与预测结果模块
   - decision.js：智能决策建议模块
   - compare.js：模型对比模块
   - exporter.js：数据导出模块
   - settings.js：系统设置模块
   - logger.js：日志记录模块

4. js/app.js
   前端应用入口，负责页面初始化、事件绑定和模块调度。

5. data
   模拟数据集：
   - realtime_hour.json：每小时实时监控数据
   - realtime_half_hour.json：每 30 分钟实时监控数据
   - history_data.json：历史电价、负荷、天气数据
   - history_data.csv：历史数据 CSV 文件
   - model_metrics.json：模型评价指标数据
   - decision_scenes.json：决策场景文案与卡片数据
   - anomaly_events.json：异常事件感知样例数据

6. scripts/generate_dataset.py
   数据集生成脚本，可重新生成 data 目录下的样例 JSON 和 CSV 数据。

7. run_server.py / 启动项目.bat
   本地运行脚本。建议使用该方式启动，避免浏览器 file:// 模式下读取 JSON 数据受限。

三、运行方式
方式 1：
双击“启动项目.bat”，系统会启动本地服务并自动打开浏览器。

方式 2：
在当前目录执行：
python run_server.py

四、模块功能对应
1. 实时数据监控：展示实时电价、平均电价、当前负荷、预测准确率，并绘制电价/负荷趋势图。
2. 历史数据查询：支持搜索、分页条数切换、趋势对比和历史数据导出。
3. 预测参数设置：支持预测天数、气温、湿度、负荷峰值、节假日、模型类型等参数输入。
4. 预测结果展示：自动生成未来电价/负荷序列、峰谷标记、图表和明细表。
5. 智能决策建议：针对工业、居民和储能电站生成差异化建议。
6. 模型对比：展示各模型 MAE、RMSE、R²、速度及综合能力。
7. 数据导出与系统设置：支持导出 CSV、PNG、决策报告和主题/字体设置。

五、说明
1. 当前版本为比赛展示型前端源码，重点展示系统结构、交互逻辑和可视化效果。
2. 数据集为模拟样例数据，用于答辩展示和功能演示。
3. 后续可直接对接真实后端接口、数据库和训练模型服务。
