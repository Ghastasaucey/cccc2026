# Screenshots Guide

The `screenshots/` folder stores competition screenshots for:
- Home dashboard
- History data module
- Forecast analysis module
- Decision recommendation module
- Model comparison module

If screenshots are regenerated, keep English file names such as:
- `home-dashboard.png`
- `history-analysis.png`
- `forecast-analysis.png`
- `decision-recommendation.png`
- `model-comparison.png`
