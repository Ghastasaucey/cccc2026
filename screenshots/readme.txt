一、项目简介
本项目为智能电价预测与决策系统的前端静态交互原型，面向竞赛设计，完整还原核心业务流程，支持本地一键启动 。
二、核心模块
首页仪表盘：实时指标展示、趋势图切换、系统日志
数据管理：历史数据查询、筛选、趋势对比
预测分析：参数自定义、模拟预测、结果可视化
决策建议：多用电场景策略生成、报告导出
模型对比：多算法性能指标可视化评估
三、本地运行
方式 1：Python 启动（推荐）
bash
运行
# 进入项目根目录，执行：
python -m http.server
# 浏览器访问 http://localhost:8000
方式 2：一键脚本
双击 start_python_server.bat 自动启动服务。
